# Benchmark: template galleries

> Summary of the `/competitor-benchmark` output, Jun 6, 2026. The full interactive page is in [artifacts/benchmark](../artifacts/benchmark/). Example data, competitors anonymised.

| Product | Filters | Search | Empty state | Notes |
|---|---|---|---|---|
| Competitor A | Channel, industry, goal as chips | Name and tags | Suggests removing a filter | Closest to what we want |
| Competitor B | Left sidebar | Name only | Blank page | Sidebar hides a third of the grid |
| Competitor C | One dropdown | Full content | "No results" text | Content search gives noisy results |

## Takeaways for us

1. Chips above the grid keep the grid wide (A).
2. Name and tag search is enough, content search adds noise (C).
3. An empty state should offer a way out, not just say "no results" (A).
