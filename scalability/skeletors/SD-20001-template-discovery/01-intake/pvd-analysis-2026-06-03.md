# PVD analysis

> Output of `/pvd-analyzer`, run on Jun 3, 2026. Example data.

## Feature intent

Help partners find the right template in Template Store faster, so they start campaigns sooner.

## Target users

| User | Need |
|---|---|
| Campaign manager at a partner | Find a template for a specific channel and goal in under a minute |
| Agency user managing several partners | Find the same template again across accounts |

## Success signals named in the PVD

- Fewer sessions that end without opening a template
- Fewer support tickets asking where a template is

## Open questions for the PM (all answered by Jun 10)

| Question | Answer |
|---|---|
| Should search include template content? | No, name and tags only for the first version |
| Is personalisation in scope? | No, postponed until usage data exists |
| Mobile web support? | Yes, but desktop first |
