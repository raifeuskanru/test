# UX research findings

> Summary of 5 interviews, Jun 9 to 12, 2026. Raw notes and recordings stay in the restricted Drive folder because they may contain partner data. Example data.

## Findings

1. **Users start from the channel, not the goal.** 4 of 5 first asked "where are the WhatsApp ones?".
2. **Scrolling is the main search strategy.** 3 of 5 scrolled the whole grid before using search.
3. **An empty result feels like a bug.** 2 users thought the page was broken when nothing matched.
4. **Agencies reuse the same templates.** P3 asked for a way to find "the one I used last week".

## What this means for the design

| Finding | Design response |
|---|---|
| 1 | Channel is the first filter group |
| 2 | Filters visible above the grid, not hidden in a menu |
| 3 | Empty state explains why and offers "Clear filters" |
| 4 | Not in scope now, added to [not-chosen.md](../not-chosen.md) as postponed |
