# Developer handoff

> Written on Oct 14, 2025. Example data.

## What to build

Clicking a template card opens a large preview in `InModal`, with "Use this template" and "Close".

## Behaviour

1. The preview shows the template at real size, scrollable.
2. "Use this template" opens the editor with the template.
3. "Close" and the Esc key return to the same scroll position in the list.

## DS approval field

No exceptions. The DS Validation Gate found nothing.
